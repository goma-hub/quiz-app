HTML・CSS・JavaScriptだけで作られた、3問または6問を選んで遊べる4択クイズアプリです。このページは現在の実装をもとに、各ファイルの役割と利用者の操作に応じた処理を図解します。

プロジェクトのファイル構成

クイズ本体は、表示の骨組み・見た目・動きの3つに分割されています。

HTML

index.html

アプリ画面の骨組みを定義します。

  • 開始・クイズ・結果の3画面
  • 問題、選択肢、フィードバックの表示場所
  • style.css と script.js の読み込み

style.css

  • カード型レイアウトとレスポンシブ表示

JAVASCRIPT

script.js

問題データ、採点、画面の切り替えを担当します。

  • questions に6問の4択データ
  • 出題数に応じて問題を取り出す
  • 回答判定とスコア集計

利用者の操作と画面遷移

最初に3問または6問を選び、回答と採点を繰り返して結果へ進みます。

1

開始画面

「3問」または「6問」を選択

2

出題を準備

startQuiz() が選んだ数だけ問題を用意

3

問題に回答

4つの選択肢のいずれかを選ぶ

4

正誤を表示

解説と「次の問題へ」を表示

5

結果画面

合計正解数を表示し、再挑戦できる

JavaScript の処理詳細

開始から出題まで

  1. 開始ボタンの data-question-count から、3または6を受け取る。
  2. startQuiz(questionCount) が currentQuestion と score を0に戻す。
  3. questions.slice(0, questionCount) で、出題する問題を activeQuestions に設定する。
  4. showQuestion() が問題文と4つの選択肢ボタンを画面に描画する。

回答から結果まで

  1. 選択肢を押すと selectAnswer() が正解番号と比較する。
  2. 全選択肢を操作不可にし、正解には緑、不正解の選択には赤のクラスを付ける。
  3. 正解なら score に1を加え、解説を表示する。
  4. 最後の問題なら「結果を見る」、それ以外なら「次の問題へ」を表示する。
  5. showResult() が「○問中○問正解」とメッセージを表示する。

通常の操作ボタン正解として表示される選択肢不正解として選んだ選択肢
